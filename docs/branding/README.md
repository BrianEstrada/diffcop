# diffcop branding

The mark is a badge with a `>_` prompt cut into it. It's drawn on a 16×16 pixel
grid, so scale it by whole multiples (16, 32, 48, 64 px…) to keep the edges
crisp.

| File              | Use                                              |
| ----------------- | ------------------------------------------------ |
| `mark.svg`        | Badge on light backgrounds                       |
| `mark-dark.svg`   | Badge on dark backgrounds                        |
| `lockup.svg`      | Badge and pixel wordmark on light backgrounds    |
| `lockup-dark.svg` | Badge and pixel wordmark on dark backgrounds     |
| `icon.svg`        | Badge on a dark rounded tile, for avatars/social |

## Colours

| Token       | Hex       |
| ----------- | --------- |
| Ink (light) | `#0d1117` |
| Ink (dark)  | `#e6edf3` |
| Cursor      | `#ff4d4f` |

The cursor is the only colour. Keep everything else ink.
